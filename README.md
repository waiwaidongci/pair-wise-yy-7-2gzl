# 古船模型帆索校准

运行：

```bash
npm start
```

访问`http://localhost:3038`。数据保存在`data/model-rigging-calibration.json`。

## 复核与交付流程

- 每项帆索任务独立流转：`待检查 / 调整中 → 待复核 → 已通过`。
- 任务可提交复核（可指派复核人）；复核时登记**复核人、结论、下一次复查日期**。
- 复核不通过时任务退回`调整中`并记录原因，交回模型负责人；调整后重新提交，**历次复核记录均保留**。
- 全部任务复核通过后，模型才能交付为`已交付`；仍有`待检查 / 调整中 / 待复核`任务时，交付保存返回 409 和未完成明细（含当前处理人和卡住环节），模型状态与已有日志不变。
- 搜索与状态筛选同时覆盖模型字段和任务内容（索具位置、状态、处理人、复核人、复核结论等）。
